
## [2026-09-08] Session — Reduce site carbon footprint (Website Carbon audit)
Status: completed — not yet deployed

### Context
Website Carbon report for pierrebeaucoral.github.io: rating **A**, **0.0566 g CO2**
per view, 0.000115 kWh, hosting flagged non-green (Green Web Foundation greencheck
returns `green:false` for GitHub Pages). The report page's "cleaner than 0%" line is
a client-side rendering glitch, not a real percentile.

Direct measurement of the live homepage found the weight was dominated by fonts:
331 KB of woff2 from fonts.gstatic.com (3 families, 11 declared faces, 5 unique
files) out of ~519 KB total — 64% of the page, over a third-party origin.

### Design Decisions
| Decision | Rationale | Alternatives |
|---|---|---|
| Pin the `opsz` axis, keep `wght` as a range | opsz is where Newsreader's bulk lives: 128.8 -> 34.3 KB with opsz pinned vs 82.5 KB with it kept. Keeping wght variable means future weight changes need no rebuild | Ship static instances per weight (smaller still, ~20 KB, but brittle); keep both axes (only -36%) |
| Do NOT move off GitHub Pages | Green hosting is a flat -9%, but `pierrebeaucoral.github.io` is a *user site*: moving means a `.pages.dev` URL unless a custom domain is bought. Would break `/NAP/`, paper links, Scholar/ORCID profiles | Cloudflare Pages / Netlify — revisit if a custom domain is ever purchased |
| Widen the subset beyond scanned glyphs | Added combining diacritics U+0300-036F (BibTeX imports arrive decomposed), spacing modifiers, and typographic spaces (French thin/narrow no-break). Costs ~5 KB total; prevents silent tofu in accented author names | Scan-only subset (5 KB smaller, brittle against new content) |
| Static number in the footer, not the Website Carbon JS badge | The official badge loads a third-party script — self-defeating for a carbon disclaimer, and adds a tracking vector | Official badge widget |
| Figure stored in `params.yaml`, not hardcoded | Must be re-tested and updated after deploy; the comment in params.yaml says so | Hardcode in the partial |

### LEARN entries
[LEARN:technical] Finding: For Google Fonts variable faces, the glyph subset is
usually NOT where the weight is — the variable axis deltas are. Subsetting
Newsreader's latin file to the site's repertoire saved 7%; pinning the `opsz`
axis saved 73%.
Impact: "Subset your fonts" is the standard advice and it is close to useless on
variable fonts. Instancing is the lever.
Apply: When self-hosting any variable webfont, check `fvar` axes first and pin
every axis the design does not actually vary.

[LEARN:gotcha] Finding: A `max-width` on an element that also carries a centering
container class (`margin:0 auto`) silently re-centres it, breaking left alignment
with its siblings.
Impact: The carbon strip sat 170px right of the copyright line above it.
Apply: Constrain the measure on the inner text element, not on the shared
layout container.
